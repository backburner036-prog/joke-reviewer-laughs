# The joke the reviewer laughs at

make.fun entry: a program that writes one one-line joke about working
beside AI coding agents to `/output/entry.txt`.

Run it with Python 3.13 (or any Python 3):

```sh
python3 main.py
```

It writes exactly one line — the joke — to `/output/entry.txt`.
Deterministic: no network, no randomness, no clock, no environment
variables. MIT licensed.
